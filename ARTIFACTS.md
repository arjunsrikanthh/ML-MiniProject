# Data and model artifacts
Source provenance: supplied project source, historical experiment records, and teammate model/data bundles. Mac/demo additions are separate local work.

The companion ML_Presentation_Package.zip includes Project/data/processed/, Project/results/models/, Project/results/xgb_extended/ and Project/demonstration/models/. Copy those directories into this root before running the saved-model demo. Use an access-controlled artifact channel agreed with the evaluator; there is no invented hosted download URL.

Run Setup Mac.command, then Open Demo.command. The notebook demo.ipynb is the live walkthrough. pipeline.ipynb explains training and may download raw data when executed. Historical result records are retained; the pipeline is not an exact replay of every follow-up run.

Large data/models and .venv are excluded from this source ZIP. Do not commit the companion full package into ordinary Git storage. This public source repository includes code and small result records; provide the companion data/model bundle separately to the evaluator.
